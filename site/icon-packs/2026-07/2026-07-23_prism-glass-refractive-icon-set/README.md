# Prism Glass Refractive Icon Set

Welcome to the Prism Glass documentation. This premium asset pack features 12 meticulously designed icons sculpted from virtual optical-grade glass. Utilizing advanced ray-tracing aesthetics, each icon splits incoming light into beautiful rainbow spectrums and casts photorealistic caustics onto its surroundings. Perfect for dark-mode interfaces and cutting-edge creative portfolios.

**Format:** SVG + ICO + PNG. Every icon ships as a transparent `1024x1024` PNG in `Icons/PNG/` (the previews below), plus vector `.svg` source and a multi-size Windows `.ico` (16-256 px) bundled in one zip.

**Using them:** drop an `.ico` onto a folder via Properties → Customize → Change Icon, or onto a shortcut via Properties → Shortcut → Change Icon. The SVGs are the source art for web, docs, and app UI — they stay sharp at any size; the PNGs are there for anything that can't take a vector.

**Container:** squircle-tile — a rounded-square (squircle) app tile with a large corner radius. Every icon in the pack shares it at the same scale.

**Redrawn as vector.** This pack originally shipped as diffusion-rendered illustrations; those renders are archived outside the repo and the icons below were redrawn as vector geometry, so they have real transparency and stay legible down to 16 px.

**Download:** [`prism-glass-refractive-icon-set-svg-ico.zip`](./prism-glass-refractive-icon-set-svg-ico.zip) — every icon as an `.svg` (vector source) and a multi-size Windows `.ico`. The PNGs below are the previews.
